# Build a Periodic Table Database

FreeCodeCamp Relational Databases v9 certification project (unit 062).

- `periodic_table.sql` — recreates the fixed `periodic_table` database (elements, properties, types).
- `element.sh` — prints an element's information given an atomic number, symbol, or name.

Built as a fleet run in timerloggedout-spec/termux-monorepo (`cert-project.yml` run 41380626948, fileset mode):
all Part 1 fix stories and the script's exact-output flows verified in-run.
